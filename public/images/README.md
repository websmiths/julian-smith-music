# Images

Drop site imagery here. Two slots are wired up so far:

- `portrait.jpg` — used as the homepage portrait (4:5 aspect, ~800×1000 ideal). If absent, the slot is hidden/empty.
- Per-band hero images — set the `image:` field in a band's frontmatter to e.g. `/images/the-magnificence.jpg`. The path is resolved against the site base. 16:9 aspect (~1600×900) recommended.

Galleries (multiple images per band) aren't built yet — let me know if you want them.
